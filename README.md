# PiCarX-AI-Vision-Control

## Overview
This repository contains the PiCarX AI Vision Control project: code, models, and utilities to enable vision-based navigation and checkpoint detection for the PiCarX robot car.

Key components:
- picar-library: core car control and vehicle utilities
- Presentations: in class slides for presentation

## Quick start
1. Install dependencies:
   - pip install -r requirements.txt
2. Verify installation:
   - pip list
3. Connect PiCarX robot to your computer.

## Repository layout
- Presentations/
  - Architecture.svg (architecture diagram — keep as-is)
- picar-library/
  - Core control and sensor modules for the PiCarX robot
- requirements.txt
  - Python dependencies to install
